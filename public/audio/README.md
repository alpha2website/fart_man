# Audio Files

Place your three audio tracks here:

| File | When it plays |
|------|---------------|
| `menu.mp3` | Main menu — loops until Play is pressed |
| `gameplay.mp3` | During gameplay — loops continuously |
| `gameover.mp3` | Plays once when Fart Man crashes |

The game handles missing files gracefully — it will run silently if the files are not present.
